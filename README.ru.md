# Simple Whitelist

Белый список с расширенным функционалом и меню на [Mantle](https://github.com/Enalian/mantle).

Вся документация для разработчиков доступна [здесь](https://enalian.github.io/simple_whitelist).

Установка **Mantle** не является обязательной, без него просто не будет доступно меню.

## 🇬🇧 English version

English version of this file you can read [here](https://github.com/Enalian/simple_whitelist/blob/master/README.md).

## 🍂 Консольные команды (сервер)

| Команда | Аргументы | Описание |
|:---:|:---|:---|
| `whitelist_on` | *Нет* | Включить белый список. |
| `whitelist_off` | *Нет* | Выключить белый список. |
| `whitelist_toggle` | *Нет* | Переключить (включить или выключить) белый список. |
| `whitelist_status` | *Нет* | Посмотреть состояние (настройки) белого списка. |
| `whitelist_add` | `<SteamID(64)/AccountID/Никнейм> [Единоразово? (1/0)]` | Добавить игрока в белый список. |
| `whitelist_remove` | `<SteamID(64)/AccountID/Никнейм>` | Удалить игрока из белого списка. |
| `whitelist_set` | `<SteamID(64)/AccountID/Никнейм> [Единоразово? (1/0)]` | Очистить белый список и добавить в него игрока. |
| `whitelist_clear` | *Нет* | Очистить белый список. |
| `whitelist_clear_duplicates` | *Нет* | Очистить белый список от дублирующийся игроков. |
| `whitelist_players` | *Нет* | Посмотреть список игроков в белом списке. |
| `whitelist_settings_save` | *Нет* | Сохранить текущие настройки в файл. |
| `whitelist_settings_load` | *Нет* | Загрузить настройки из файла. |
| `whitelist_joinkick_reason` | `<Причина>` | Установить причину кика при выходе с сервера. |
| `whitelist_kick_reason` | `<Причина>` | Установить причину кика при включении БС (белого списка). |
| `whitelist_kick` | `<1/0>` | Кикать игроков и ботов при включении БС? (1 = Да, 0 = Нет)  |
| `whitelist_kick_bots` | `<1/0>` | Кикать ботов при включении БС? (1 = Да, 0 = Нет) |
| `whitelist_password_check` | `<1/0>` | Требовать пароль при входе на сервер (во время работы БС)? (1 = Да, 0 = Нет) |
| `whitelist_date_format` | `<Формат>` | Формат даты (для причин). |
| `whitelist_time_format` | `<Формат>` | Формат времени (для причин). |
| `whitelist_save_names` | `<1/0>` | Сохранять имена игроков в БД сервера? (1 = Да, 0 = Нет) |
| `whitelist_save_settings` | `<1/0>` | Сохранять настройки в файл? (1 = Да, 0 = Нет) |
| `whitelist_logs` | `<1/0>` | Включить логирование сообщений и действий? (1 = Да, 0 = Нет) |
| `whitelist_language` | `<Язык>` | Установить язык сервера. |
| `whitelist_ipasswords_enable` | `<1/0>` | Включить модуль индивидуальных паролей. |
| `whitelist_ipasswords_pepper` | `<Текст>` | Установить новый перец для индивидуальных паролей. |
| `whitelist_ipassword_set` | `<SteamID(64)/AccountID/Никнейм> <Пароль>` | Установить игроку индивидуальный пароль для входа на сервер. |
| `whitelist_ipassword_remove` | `<SteamID(64)/AccountID/Никнейм>` | Убрать индивидуальный пароль для игрока. |

## ⚪ Заполнители для причин

| Заполнитель | Описание | Пример |
|:---:|:---|:---|
| `{{player}}` | Никнейм игрока | `Enalian` |
| `{{player.steamid}}` | [SteamID](https://wiki.facepunch.com/gmod/Player:SteamID) игрока | `STEAM_0:0:0` |
| `{{player.steamid64}}` | [SteamID64](https://wiki.facepunch.com/gmod/Player:SteamID64) игрока | `76561197960265728` |
| `{{player.accountid}}` | [AccountID](https://wiki.facepunch.com/gmod/Player:AccountID) игрока | `123456789` |
| `{{player.ip}}` | IP-Адрес игрока | `127.0.0.1` |
| `{{n}}` | Новая строка | `\n` |
| `{{t}}` | Символ табуляции | `\t` |
| `{{date}}` | Дата | `09/16/98` |
| `{{time}}` | Время | `23:48:10` |
| `{{datetime}}` | Дата + время | `09/16/98 23:48:10` |

## 🕛 Форматы времени и даты

| Формат | Описание | Пример |
|:---:|:---|:---|
| `%a` | Аббривеатурное имя дня недели | `Wed` |
| `%A` | Полное имя дня недели | `Wednesday` |
| `%b` | Аббривеатурное имя месяца | `Sep` |
| `%B` | Полное имя месяца | `September` |
| `%d` | День месяца [01-31] | `16` |
| `%H` | Час в 24-часовом формате [00-23] | `23` |
| `%I` | Час в 12-часовом формате [01-12] | `11` |
| `%j` | День года [001-365] | `259` |
| `%m` | Месяц [01-12] | `09` |
| `%M` | Минута [00-59] | `48` |
| `%p` | Либо `am`, либо `pm` | `pm` |
| `%S` | Секунда [00-60] | `10` |
| `%w` | День недели [0-6 = Воскресенье-Суббота] | `3` |
| `%W` | Неделя в году [00-53] | `37` |
| `%x` | Дата (Тоже, что и `%m/%d/%y`) | `09/16/98` |
| `%X` | Время (Тоже, что и `%H:%M:%S`) | `23:48:10` |
| `%y` | Год (две цифры) [00-99] | `98` |
| `%Y` | Полный год | `1998` |
| `%z` | Часовой пояс | `-0300` |
| `%%` | Знак процента | `%` |

## 📩 Установка

### Steam Workshop

Рекомендуется подписаться на [аддон в Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3825350203) и добавить аддон в коллекцию сервера. Это позволит аддону обновляться самостоятельно без его ручной переустановки.

### Самостоятельная загрузка

Скачайте [последний релиз](https://github.com/Enalian/simple_whitelist/releases/latest/download/simple_whitelist.zip) со страницы [Releases](https://github.com/Enalian/simple_whitelist/releases) и распакуйте его в папку `garrysmod/addons`.
