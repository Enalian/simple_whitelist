🟦 IRNWhitelist.Whitelist.SetOn(boolean bool)

## Description
---

Change whitelist state (enable or disable)

## Arguments
---

`1` **`boolean`** **bool**  
&emsp;New state (true = enable, false = disable)

## Example
---

```lua

```
