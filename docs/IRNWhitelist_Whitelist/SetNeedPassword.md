🟦 IRNWhitelist.Whitelist.SetNeedPassword(boolean bool)

## Description
---

Set password neeed white player joining (on enabled whitelist)

## Arguments
---

`1` **`boolean`** **bool**  
&emsp;Need password? (true = password needed, false = password not needed)

## Example
---

```lua
IRNWhitelist.Whitelist.SetNeedPassword(true)
```
