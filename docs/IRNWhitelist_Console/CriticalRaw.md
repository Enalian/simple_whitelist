---
title: IRNWhitelist.Console.CriticalRaw
---

```lua
🟦🟨 IRNWhitelist.Console.CriticalRaw(string str, boolean? no_log)
```

## Description
---

Print raw critical error text into client console

## Arguments
---

`1` **`string`** **str**  
&emsp;Text to print

`2` **`boolean?`** **no_log** *(optional)*  
&emsp;Need to be logged?

## Example
---

```lua
IRNWhitelist.Console.CriticalRaw(IRNWhitelist.Lang:FormatPhrase(phrase, ...))
```
