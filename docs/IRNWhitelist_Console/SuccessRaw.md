---
title: IRNWhitelist.Console.SuccessRaw
---

```lua
🟦🟨 IRNWhitelist.Console.SuccessRaw(string str, boolean? no_log)
```

## Description
---

Print raw success message text into client console.

## Arguments
---

`1` **`string`** **str**  
&emsp;Text to print.

`2` **`boolean?`** **no_log** *(optional)*  
&emsp;Need to be logged?

## Example
---

```lua
IRNWhitelist.Console.SuccessRaw(IRNWhitelist.Lang:FormatPhrase(phrase, ...))
```
