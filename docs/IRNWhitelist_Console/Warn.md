🟦🟨 IRNWhitelist.Console:Warn(string phrase, string ...)

## Description
---

## Arguments
---

`1` **`string`** **phrase**  
&emsp;Phrase (or text) to print

`2` **`string`** **...**  
&emsp;Format strings

## Example
---

```lua
IRNWhitelist.Console:Warn("Language '{{1}}' not found.", lang)
```
