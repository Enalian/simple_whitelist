    Get

    🟦 any IRNWhitelist.CVars:Get(string name, string cv_type, any? default)

    Description

    Get ConVar value.

    Arguments

    1 string name
     The ConVar name.

    2 string cv_type
     The ConVar type.

    3 any? default (optional)
     Default value.

    Returns

    1 any
     Return value.

    Example

    string.format("commands.%s", IRNWhitelist.CVars:Get("enable", "bool", false) and "enable" or "disable")
